## What is RAG?

Retrieval-Augmented Generation (RAG) retrieves relevant documents before calling an LLM,
so answers are grounded in your own knowledge base instead of model memory alone.

## What is MCP?

Model Context Protocol (MCP) standardizes how AI apps expose tools, resources, and prompts
so agents can call APIs and take actions beyond plain text generation.

## How do RAG and MCP work together?

RAG supplies factual context from documents. MCP (or tool-calling) lets the agent fetch live
data and perform actions such as looking up orders, customers, or weather.
